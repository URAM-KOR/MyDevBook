## 1️⃣ Users (사용자)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID / BIGINT | 사용자 고유 ID |
| name | VARCHAR | 사용자 이름 |
| email | VARCHAR | 이메일 / 로그인 ID |
| provider_id | VARCHAR | Google 계정 고유 ID
| provider | VARCHAR | "google"
| created_at | TIMESTAMP | 계정 생성일 |
| updated_at | TIMESTAMP | 마지막 수정일 |

## 2️⃣ Portfolios (포트폴리오 + 상세 항목)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID / BIGINT | 포트폴리오/항목 고유 ID |
| user_id | UUID / BIGINT | 작성자 ID (Users.id 참조) |
| title | VARCHAR | 포트폴리오/항목 제목 |
| content | TEXT | 상세 내용 |
| status | VARCHAR | 상태 (예: active / archived) |
| order | INT | 화면 표시 순서 |
| created_at | TIMESTAMP | 생성일 |
| updated_at | TIMESTAMP | 마지막 수정일 |

---

## 3️⃣ Portfolio_Trackings (추적 / 상태 감지)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID / BIGINT | 추적 항목 고유 ID |
| portfolio_id | UUID / BIGINT | 포트폴리오 ID 참조 |
| url | TEXT | 상태를 확인할 URL |
| last_status | VARCHAR | 마지막 확인 상태 |
| logic_prompt | TEXT | GPT API에 보낼 프롬프트 (로직) |
| last_checked_at | TIMESTAMP | 마지막 확인 시각 |
| created_at | TIMESTAMP | 생성일 |
| updated_at | TIMESTAMP | 마지막 수정일 |

---

## 4️⃣ Notifications (알림)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID / BIGINT | 알림 고유 ID |
| user_id | UUID / BIGINT | 대상 사용자 |
| tracking_id | UUID / BIGINT | 관련 추적 항목 참조 |
| type | VARCHAR | 알림 타입 |
| payload | JSON | 알림 관련 데이터 |
| read | BOOLEAN | 확인 여부 |
| created_at | TIMESTAMP | 생성일 |
| sent_at | TIMESTAMP | 발송일 |

---

## 5️⃣ Push_Subscriptions (웹푸쉬 구독)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID / BIGINT | 구독 고유 ID |
| user_id | UUID / BIGINT | 구독한 사용자 ID |
| endpoint | TEXT | Push API endpoint URL |
| keys | JSON | p256dh, auth 등 키 정보 |
| created_at | TIMESTAMP | 구독 생성일 |
| updated_at | TIMESTAMP | 마지막 갱신일 |

---

## 6️⃣ 서비스 흐름

1. 사용자가 포트폴리오/상세 항목을 등록/수정/삭제  
2. Portfolio_Trackings 테이블에 URL + logic_prompt 등록  
3. 서비스 레이어에서 주기적으로 Tracking 조회  
4. URL 데이터 수집 → logic_prompt와 함께 GPT API 호출  
5. GPT 결과 → last_status 업데이트  
6. 상태 변화가 감지되면 Notifications 테이블에 알림 생성  
7. Web Push 구독 정보가 있는 경우 Push_Subscriptions 참고 → 알림 발송  
8. 사용자는 웹에서 알림 확인, 클릭 시 포트폴리오 상세 페이지로 이동

## 💡 핵심 포인트
- **로직은 GPT 프롬프트로 정의** → 코드 변경 최소화  
- DB: 데이터 + 판단 기준만 저장  
- Service Layer: 상태 확인, GPT API 호출, 알림 생성 및 발송 담당  
- Portfolios와 상세 항목 단일 테이블로 단순화  
- 확장 가능: 새로운 추적 URL, GPT 로직, 알림 유형 추가 가능

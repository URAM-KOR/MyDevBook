# Development Guidelines (인디 개발용)

> 최소 기준: AI + 혼자 개발용. 필요시 확장 가능.

---

## 1. Code Style
- Indentation: 2 spaces
- Variables: camelCase
- Functions: verbNoun()  
- Classes: PascalCase
- Constants: UPPER_SNAKE_CASE
- Comments: 간결하게, 필요 시 영어로 작성

---

## 2. File / Folder Structure
/src
/components # UI 컴포넌트
/pages # 페이지 / 라우트
/utils # 공통 유틸 함수
/api # API 호출 모듈
/tests # 테스트 파일
.env # 환경변수


---

## 3. Coding Rules
- No hardcoding: 모든 환경/상수값은 `.env` 또는 config 사용
- No magic numbers/strings
- API 호출: fetchWrapper / axiosInstance 등 통일
- State management: 가능한 단일 source of truth
- Error handling: 항상 try/catch 또는 에러 반환 처리

---

## 4. Git / Version Control
- Branches: `main`, `develop`, `feature/*`
- Commit message: `type(scope): message`
  - types: feat, fix, refactor, docs, chore
- Pull Request: 설명 + 관련 issue/PR 링크 필수

---

> Tip: 이 가이드라인을 AI에게 주고 “이 기준으로 전체 프로젝트 scaffolding 생성해줘”라고 하면  
> 거의 그대로 스타일/구조/API 기준을 반영해서 코드를 만들어줌

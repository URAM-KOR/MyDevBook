# Design Contract – Portfolio UI

1. Layout Rule
2. Grid Rule
3. Card Rule
4. Responsive Rule
5. Spacing System


## 1. Layout Rule
- Base container width: max 1280px
- Horizontal padding: 32px
- Content align: center
- Section vertical spacing: 56px
- 카드를 4열로 나열해줘

## 2. Grid Rule
- Default: 4 columns
- Breakpoints:
  - < 640px : 1 column
  - 640px – 1024px : 2 columns
  - 1024px – 1280px : 3 columns
  - > 1280px : 4 columns
- Gap (grid spacing): 24px

## 3. Card Rule
- Min width: 240px
- Border radius: 16px
- Shadow: md (default), lg (hover)
- Transition: 200ms ease
- Image:
  - Height: 160px
  - Object-fit: cover
- Content padding: 20px

## 4. Card Content Rule
- Title:
  - Font size: 18px
  - Weight: semibold
- Description:
  - Font size: 14px
  - Max lines: 2
  - Color: gray-600
- Buttons:
  - Size: small
  - Rounded: 8px
  - Layout: horizontal gap 8px

## 5. Spacing System
- XS: 4px
- SM: 8px
- MD: 16px
- LG: 24px
- XL: 32px
- Section: 56px

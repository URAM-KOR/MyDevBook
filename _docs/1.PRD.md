    # PRD - Product Requirements Document (본질 중심)

    ## 1️⃣ 목적 / 문제점
    - 서비스 이름:  MyDevBook
    - 문제 또는 필요성:  포트폴리오를 체계적으로 리스팅하고, 성실함 및 인지 부족 문제를 보완하기 위해
    - 사용 맥락 (Where / When / 어떤 상황에서 쓰이는가):  일상
    - 예시: 출근길, 기상 직후, 일상, 휴식, 킬링타임, 공부, 카페, 학교 등

    ## 2️⃣ 해결방안 / 핵심 기능
    - 핵심 기능:  포트폴리오 리스팅, 상태 알림 푸쉬
    - 기능 상세 동작 방식:  사용자가 포트폴리오를 등록/조회/정리, 주기적 API 응답 모니터링, 상태 변화 발생 시 푸쉬 알림 (Web Push API + Service Worker)

    ## 3️⃣ 사용자 흐름
    - 주요 화면 / 페이지:  웹(PWA고려)
    - 화면 간 이동 흐름:  스크롤 카드 형태, 단일 페이지, 카드 선택 시 상세 보기

## 1️⃣ 핵심 모듈
1. 서비스가 제공하는 핵심 기능은 무엇인가요?  
- 포트폴리오를 체계적으로 리스팅하고 관리  
- 상태 변화 알림 제공 (Web Push API + Service Worker)

2. 각 기능을 담당하는 모듈/컴포넌트는 무엇인가요?  
- **프론트엔드:** Next.js 기반 웹(PWA 고려)  
- **백엔드:** Next.js API 서버, 상태 모니터링 로직  
- **데이터베이스:** 포트폴리오 데이터 및 알림 구독 정보 저장  
- **알림 처리:** Web Push 전송 및 Service Worker

---

## 2️⃣ 데이터 흐름
3. 데이터가 서비스 안에서 어떻게 흐르나요?  
- 사용자가 포트폴리오 등록/수정/삭제  
- API 서버에서 요청 처리 후 DB에 반영  
- 상태 변화가 있으면 알림 전송  
- 클라이언트에서 화면에 최신 상태 표시

4. 상태 변화나 이벤트는 어떻게 처리되나요?  
- 주기적 API 상태 확인 또는 이벤트 발생 시 서버에서 감지  
- 감지된 이벤트를 구독 정보 기준으로 Web Push 알림 전송

---

## 3️⃣ 사용자 경험
5. 사용자가 서비스를 사용할 때 화면과 기능은 어떻게 연결되나요?  
- 스크롤 카드 형태 메인 페이지 → 카드 선택 시 상세 보기  
- 포트폴리오 등록/수정/삭제 시 상태가 업데이트되고 알림 전송  
- 알림 클릭 시 해당 포트폴리오 상세 페이지로 이동

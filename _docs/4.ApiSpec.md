## 1️⃣ Authentication (Google OAuth)

### Google 로그인

- **Method:** `GET`
- **URL:** `/api/auth/google`
- **Request:** 없음
- **Response:** 없음 (리디렉션)
- **설명:** 클라이언트를 Google 로그인 페이지로 리디렉션

---

### Google 콜백

- **Method:** `GET`
- **URL:** `/api/auth/google/callback?code={code}`
- **Request:** 없음 (Query Parameter: `code`)
- **Response Example:**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "user-1234",
    "name": "Kim Wooram",
    "email": "wooram@example.com",
    "provider": "google",
    "provider_id": "google-5678"
  }
}
```
- **설명:** OAuth 인증 후 JWT 토큰 발급, 사용자 DB 등록/조회

## 2️⃣ Portfolios

### 등록

- **Method:** `POST`
- **URL:** `/api/portfolios`
- **Request Example:**
```json
{
  "user_id": "user-1234",
  "title": "AI Project",
  "content": "OpenVLA 기반 로봇 제어",
  "order": 1
}
```
- **Response Example:**
```json
{
  "id": "portfolio-5678",
  "user_id": "user-1234",
  "title": "AI Project",
  "content": "OpenVLA 기반 로봇 제어",
  "order": 1,
  "status": "active",
  "created_at": "2025-12-03T12:00:00Z"
}
```

---

### 조회

- **Method:** `GET`
- **URL:** `/api/portfolios?user_id={user_id}`
- **Response Example:**
```json
[
  {
    "id": "portfolio-5678",
    "title": "AI Project",
    "content": "OpenVLA 기반 로봇 제어",
    "order": 1,
    "status": "active"
  },
  {
    "id": "portfolio-6789",
    "title": "Portfolio App",
    "content": "React + PWA",
    "order": 2,
    "status": "active"
  }
]
```

---

### 수정

- **Method:** `PUT`
- **URL:** `/api/portfolios/{portfolio_id}`
- **Request Example:**
```json
{
  "title": "AI Project v2",
  "content": "OpenVLA 로봇 제어 개선",
  "order": 1,
  "status": "active"
}
```
- **Response:** `200 OK`

---

### 삭제

- **Method:** `DELETE`
- **URL:** `/api/portfolios/{portfolio_id}`
- **Response:** `200 OK`

---

## 3️⃣ Tracking (GPT 기반 상태 추적)

### 등록

- **Method:** `POST`
- **URL:** `/api/trackings`
- **Request Example:**
```json
{
  "portfolio_id": "portfolio-5678",
  "url": "https://example.com/status",
  "logic_prompt": "이 URL의 상태를 '성공/실패'로 판단하고 요약해줘"
}
```
- **Response Example:**
```json
{
  "id": "tracking-9012",
  "portfolio_id": "portfolio-5678",
  "url": "https://example.com/status",
  "logic_prompt": "이 URL의 상태를 '성공/실패'로 판단하고 요약해줘",
  "last_status": null,
  "last_checked_at": null,
  "created_at": "2025-12-03T12:10:00Z"
}
```

---

### 상태 조회

- **Method:** `GET`
- **URL:** `/api/trackings?portfolio_id={portfolio_id}`
- **Response Example:**
```json
[
  {
    "id": "tracking-9012",
    "url": "https://example.com/status",
    "logic_prompt": "이 URL의 상태를 '성공/실패'로 판단하고 요약해줘",
    "last_status": "success",
    "last_checked_at": "2025-12-03T12:15:00Z"
  }
]
```

---

## 4️⃣ Notifications

### 조회

- **Method:** `GET`
- **URL:** `/api/notifications?user_id={user_id}`
- **Response Example:**
```json
[
  {
    "id": "notif-3456",
    "tracking_id": "tracking-9012",
    "type": "portfolio_update",
    "payload": {},
    "read": false,
    "created_at": "2025-12-03T12:20:00Z"
  }
]
```

---

### 읽음 처리

- **Method:** `PUT`
- **URL:** `/api/notifications/{notification_id}/read`
- **Response:** `200 OK`

## 5️⃣ Push Subscriptions (웹푸시)

### 구독 등록

- **Method:** `POST`
- **URL:** `/api/push-subscriptions`
- **Request Example:**
```json
{
  "user_id": "user-1234",
  "endpoint": "https://fcm.googleapis.com/fcm/send/abc123",
  "keys": {
    "p256dh": "BEx...",
    "auth": "a1b2c3d4"
  }
}
```
- **Response:** `201 Created`

---

### 구독 삭제

- **Method:** `DELETE`
- **URL:** `/api/push-subscriptions/{subscription_id}`
- **Response:** `200 OK`
